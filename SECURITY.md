# Security Policy

## Supported versions

Security fixes are considered for the current `main` branch and the latest
formal release. Earlier releases are not supported.

## Reporting a vulnerability

Please [report suspected security vulnerabilities privately](https://github.com/Guan-Pujun/bcmp-python/security/advisories/new)
through GitHub's private vulnerability reporting for this repository. Do not
disclose the details in a public issue.

## Response and fixes

BCMP is maintained on a best-effort basis and does not offer a guaranteed
response or fix timeline. If a report is accepted, we will work to address it
privately and publish a bug-fix release when appropriate.
