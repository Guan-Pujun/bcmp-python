# Contributing to BCMP<sup>Py</sup>

## Feedback and bug reports

Use the [GitHub issue tracker](https://github.com/Guan-Pujun/bcmp-python/issues)
for reproducible bug reports, enhancement requests, and questions about public
package behavior. Include the BCMP version, Python version, a minimal example,
the expected result, and the observed result where possible.

Do not use public issues for suspected security vulnerabilities. Follow
[SECURITY.md](SECURITY.md) instead.

## Discussing a change

For a substantial behavior or API change, open an issue first to discuss the proposal and coordinate the work.

## Submitting a change

1. Create a focused branch from `main`.
2. Open a pull request with the smallest coherent change.
3. Add or update a test when public behavior changes.
4. Update the manual when installation, public behavior, or result
   interpretation changes.
